Cookie Policy

Plain-language version — this describes exactly what this NexCore instance does, not a generic template.

NexCore is self-hosted software: the person running this server controls it, and this page describes the cookies the software itself sets. It does not send data to any third party — there's no analytics provider, ad network, or external tracker built into it.

Cookies this site sets

CookiePurposeCategoryLifetime
nexcore_session Keeps you signed in between page loads. Necessary 30 days
nexcore_consent Remembers your cookie preference so we don't ask every visit. Necessary 180 days
nexcore_ui Remembers your last-open folder and grid/list view. Only set if you opt in below. Functional 180 days

Analytics

This build doesn't include any analytics or tracking script. The "Analytics" toggle in preferences exists so the pattern is there if the person hosting this server ever adds an analytics tool — turning it on today does not cause anything to run.

Your choices

You can accept all cookies, use only the necessary ones, or pick exactly which optional categories you're comfortable with. Necessary cookies can't be turned off because the site can't keep you signed in without one of them.

Questions

Since this is self-hosted software, questions about how a particular instance is run should go to whoever operates that server — NexCore itself doesn't operate a hosted service or collect anything centrally.
